# M6.7 — Xuất bản toàn bộ Project

Sidebar **Workspace** có thêm lệnh **Xuất bản**. Màn hình này đọc các chương đang hoạt động theo thứ tự `ProjectCatalog` và ghép thành đúng một file:

- TXT UTF-8, có thể gồm tên Project và tiêu đề từng chương.
- PDF A4, mỗi chương bắt đầu ở trang mới, có số trang và font Unicode tiếng Việt.

Nội dung từng chương luôn do `ChapterTranslationComposer` tạo, cùng quy tắc đang dùng cho Reader và lệnh xuất TXT một chương. Chương đã xóa mềm bị loại khỏi kế hoạch. Không thay đổi Project manifest, chapter, draft, approval, history, queue hoặc schema dữ liệu.

## Bảo vệ dữ liệu

- Kiểm tra toàn bộ trạng thái trước khi bật nút xuất. Nếu còn chương thiếu bản dịch hoặc cần kiểm tra, người dùng phải bật xác nhận xuất bản nháp.
- Đọc từng `ChapterDocument` theo thứ tự thay vì nạp tất cả chapter body vào RAM.
- Ghi vào file tạm cùng thư mục đích. Chỉ thay file đích sau khi hoàn tất; lỗi đọc, hủy hoặc lỗi ghi giữ nguyên file đích cũ.
- Revision của Project được kiểm tra trong suốt tác vụ. Nếu queue, Editor hoặc thao tác khác cập nhật Project, lần xuất dừng và yêu cầu người dùng chạy lại.
- Khi ghi đè một file xuất đã có, phiên bản trước được giữ ở file `.bak`.
- File đích phải nằm ngoài thư mục dữ liệu Project; thao tác từ chối mọi đường dẫn có thể ghi đè manifest, chapter, settings hoặc tài nguyên Project.

PDF dùng `PDFsharp-MigraDoc-WPF` 6.2.4 theo giấy phép MIT. Bản publish kèm `THIRD-PARTY-NOTICES.txt`.

## Kiểm thử tự động

- Thứ tự đọc, tiêu đề và nội dung ghép chuẩn dùng chung với Reader.
- Bỏ qua chapter xóa mềm.
- Không ghi Project khi kiểm tra hoặc xuất.
- Yêu cầu xác nhận đối với bản nháp; bảo toàn file đích khi lỗi giữa chừng hoặc revision thay đổi.
- Sidebar, trạng thái màn Xuất bản và file PDF Unicode thật có thể mở lại.
- Regression ngày 14/10/2026: Core **576/576**, WPF **68/68**, tổng **644/644**; Release build 0 lỗi, 0 cảnh báo.

Giới hạn hiện tại: PDF dựng một document trước khi render nên có thể dùng nhiều RAM hơn TXT với truyện cực dài. TXT là lựa chọn nhẹ hơn cho Project hàng nghìn chương. Chưa có bìa, mục lục PDF, metadata nâng cao hoặc chia nhiều tập.
